Angola's licence plates for the plate_core library — the 1996 white-on-black series, themes, alphabets, advisory validator.

## Quick start

### Install (TypeScript)

Copy `typescript/src/countries/angola/` into `plate_core/typescript/src/countries/`.

Then run the tests from `plate_core/typescript/`: `npm test`.

### Use

```ts
import country from './countries/angola';

const spec = country.specs.get('ao.standard');
console.log(country.package);
```

## Specs

The specs are the same in every language (they come from shared data).

- `ao.standard`
- `ao.stacked`

## Themes

- `AngolaThemes.standard`
- `AngolaThemes.stacked`

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`AngolaValidator`).
