## Quick start

### Install (Python)

Copy `python/plates/countries/angola/` into `plate_core/python/plates/countries/`.

Then run the tests from `plate_core/python/`: `pytest`.

### Use

```python
from plates.countries.angola.data import SPECS, THEMES

spec = SPECS["ao.standard"]
theme = THEMES["AngolaThemes.standard"]
print(spec.id)
```

## Specs

The specs are the same in every language (they come from shared data).

- `ao.standard`
- `ao.stacked`

## Themes

- `AngolaThemes.standard`
- `AngolaThemes.stacked`

## Change it

- Pick a spec: use another key of `SPECS`.
- Pick a theme: use another key of `THEMES`.
- Validators: `VALIDATORS` maps the names `AngolaValidator` to classes.
