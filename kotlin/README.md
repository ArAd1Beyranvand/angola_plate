## Quick start

### Install (Kotlin)

Copy `kotlin/src/commonMain/kotlin/plates/countries/angola/` into `plate_core/kotlin/src/commonMain/kotlin/plates/countries/`.

Then run the tests from `plate_core/kotlin/`: `./gradlew jvmTest`.

### Use

```kotlin
import plates.countries.angola.country

val spec = country.specs["ao.standard"]
println(country.pkg)
```

## Specs

The specs are the same in every language (they come from shared data).

- `ao.standard`
- `ao.stacked`

## Themes

- `AngolaThemes.standard`
- `AngolaThemes.stacked`

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`AngolaValidator`).
